# 📈 Stock Market Data Analyzer

## 🚀 Project Overview

The Stock Market Data Analyzer is a Python-based financial analysis project that fetches historical stock market data, analyzes stock trends, calculates returns and volatility, and generates visual charts for better investment analysis.

The project uses Yahoo Finance data and provides interactive visualizations using Streamlit and Matplotlib.

---

# 🎯 Problem Statement

Analyzing stock market trends manually can be difficult and time-consuming.

This project automates:
- Stock data collection
- Trend analysis
- Moving average calculation
- Daily returns calculation
- Volatility analysis
- Visualization generation
- Final report generation

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/Stock-Market-Data-Analyzer.git
```

## Open Project Folder

```bash
cd Stock-Market-Data-Analyzer
```

## Create Virtual Environment

```bash
python -m venv venv
```

## Activate Virtual Environment

### Windows

```bash
venv\Scripts\activate
```

### Mac/Linux

```bash
source venv/bin/activate
```

## Install Required Libraries

```bash
pip install -r requirements.txt
```

---

# ▶️ Run Project

```bash
streamlit run main.py
```
